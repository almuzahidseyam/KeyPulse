# Contributing to KeyPulse

First off, thank you for considering contributing to KeyPulse!

### 1. Where do I go from here?
If you've noticed a bug or have a feature request, make sure to check our Issues tab to see if someone else in the community has already created a ticket. If not, go ahead and make one!

### 2. Fork & create a branch
If this is something you think you can fix, then fork KeyPulse and create a branch with a descriptive name.

### 3. Implement your fix or feature
At this point, you're ready to make your changes! Feel free to ask for help; everyone is a beginner at first.

### 4. Make a Pull Request
At this point, you should switch back to your master branch and make sure it's up to date with KeyPulse's master branch. Then create a pull request with a clear description of your changes.
